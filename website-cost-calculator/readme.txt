A comprehensive website cost calculator that helps clients estimate website project costs with a beautiful, multi-step interface.

== Description ==

Website Cost Calculator is a powerful and flexible tool that allows web development agencies and freelancers to provide instant cost estimates to potential clients.

**Key Features:**

* Multi-step calculator with progress indicator
* Fully customizable pricing options
* Modern, responsive design
* Real-time price calculations
* Built-in lead capture form
* Email notifications for new quotes
* Quote management in WordPress admin
* Customizable colors and branding
* Rush/urgent pricing multipliers
* Monthly maintenance plan options

**Perfect For:**

* Web Development Agencies
* Freelance Web Developers
* Digital Marketing Agencies
* Design Studios
* IT Service Providers

**Calculator Steps:**

1. Website Type - Choose the type of website needed
2. Pages & Design - Select page count and design approach
3. Features - Pick from various website features
4. Extras - Add SEO, marketing, and maintenance options
5. Summary - Review and submit quote request

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/website-cost-calculator` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to Cost Calculator → Settings to configure your pricing
4. Add `[website_cost_calculator]` shortcode to any page

== Frequently Asked Questions ==

= How do I add the calculator to a page? =

Use the shortcode `[website_cost_calculator]` on any page or post.

= Can I customize the prices? =

Yes! All prices are fully customizable from the Cost Calculator → Settings page in your WordPress admin.

= Will it work with my theme? =

The calculator is designed to work with any WordPress theme. It uses its own contained styles that shouldn't conflict with your theme.

= Can I change the colors? =

Yes, go to Cost Calculator → Settings → Styling to customize all colors to match your brand.

= Where are quote submissions stored? =

All submissions are stored in your WordPress database and can be viewed at Cost Calculator → Quote Requests.

= Can I receive email notifications? =

Yes, both admin and customer email notifications are sent automatically when a quote is submitted.
